📚 Tarea 2: Base de Datos

Diseño e Implementación de Sistemas de Bases de Datos

🎯 Objetivo

Desarrollar una comprensión profunda de los sistemas de gestión de bases de datos, incluyendo el diseño relacional, la normalización de datos, y la implementación de soluciones prácticas utilizando SQL. Se enfatiza la importancia de la integridad de datos y la optimización de consultas en aplicaciones empresariales.

💡 Conceptos Clave

Modelo Relacional

Fundamento de las bases de datos modernas. Organiza datos en tablas con relaciones definidas mediante claves primarias y foráneas.

Normalización

Proceso de organización de datos para minimizar redundancia y dependencias. Incluye formas normales (1NF, 2NF, 3NF, BCNF).

SQL (Structured Query Language)

Lenguaje estándar para gestionar bases de datos. Permite crear, leer, actualizar y eliminar datos (CRUD).

Transacciones

Operaciones que garantizan la consistencia de datos. Implementan ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad).

Índices

Estructuras que mejoran la velocidad de búsqueda. Esenciales para el rendimiento en bases de datos grandes.

Integridad Referencial

Mecanismo que garantiza la validez de las relaciones entre tablas. Previene datos huérfanos o inconsistentes.

Comandos SQL Implementados

Se utilizaron diversos comandos SQL para garantizar la integridad y funcionalidad de la base de datos:

-- Creación de tablas con integridad referencial
CREATE TABLE usuarios (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Índices para optimización
CREATE INDEX idx_email ON usuarios(email);

-- Consultas con JOINs
SELECT u.nombre, COUNT(p.id) as num_productos
FROM usuarios u
LEFT JOIN productos p ON u.id = p.usuario_id
GROUP BY u.id;

📋 Conclusiones

📚 Aprendizajes Principales

La normalización de datos es crucial para crear bases de datos escalables y mantenibles. El dominio de SQL y las técnicas de optimización son esenciales para cualquier profesional de datos.

⚠️ Desafíos Encontrados

Balancear entre la normalización ideal y el rendimiento práctico fue desafiante. Las consultas complejas requieren validación exhaustiva para garantizar resultados correctos.

🎯 Mejoras Futuras

Implementar replicación de bases de datos, backup automático, y monitoreo en tiempo real. Explorar NoSQL para casos de uso específicos.
