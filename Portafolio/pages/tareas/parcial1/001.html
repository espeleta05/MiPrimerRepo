TAREA 001

Configuración de Ubiquitous y Google Cloud

Configuración inicial del servidor Ubiquitous y creación de la primera máquina virtual en Google Cloud.

20 ENE Fecha
3.5 HRS Duración
COMPLETADA Estado
MEDIA Dificultad
1

Objetivo y Contexto

Fecha de ejecución: 20 de Enero, 2026

🎯 Objetivo Principal

En esta sesión trabajamos en dos objetivos principales:

  • Configurar y utilizar Ubiquitous: Aprender a acceder al servidor de la escuela y crear nuestra página personal.
  • Crear una VM en Google Cloud: Configurar nuestra primera máquina virtual e instalar MariaDB.

📋 Contexto de la Actividad

  • Cada estudiante tiene una cuenta en el servidor Ubiquitous donde se alojarán todas las tareas.
  • Previamente configuramos nuestras cuentas de Google Cloud con facturación habilitada.
2

Procedimiento y Desarrollo

🔧 Pasos realizados

  1. Conexión SSH al servidor Ubiquitous
  2. Creación de estructura de carpetas
  3. Configuración de SFTP con CyberDuck
  4. Creación de VM en Google Cloud
  5. Instalación de MariaDB

💻 Código ejecutado

# Actualización del sistema $ sudo yum update -y # Instalación de MariaDB $ sudo yum install mariadb-server -y # Habilitar servicio $ sudo systemctl enable mariadb $ sudo systemctl start mariadb
